👋 So funktioniert's

  1. Die Liste sammelt IT-Stellen aus mehreren Portalen und aktualisiert sich zweimal täglich.
  2. Jede Stelle wird mit dem Profil verglichen (Jamf, Intune, M365/Entra, PowerShell, Allrounder …). 🎯 Top-Match zeigt die besten Treffer.
  3. Oben filterst du nach Thema, unter Filter gibt es Pensum, Umkreis, Rolle und das Ausblenden von Personalvermittlern.
  4. Bei jeder Stelle kannst du sie ☆ merken, als ✓ beworben markieren oder ✕ ausblenden.
